# Credits

Model files in `models/` come from two MIT-licensed projects. The per-model output format and several Quick models were adapted from a third.

- **cyperx84/claude-skills-mental-models**: activation-energy, asymmetric-warfare, bias-from-incentives, bottlenecks, confirmation-bias, creative-destruction, emergence, feedback-loops, first-principles-thinking, framing, inertia, inversion, leverage, margin-of-safety, randomness, regression-to-the-mean, sampling, scarcity, second-order-thinking, social-proof, trade-offs. https://github.com/cyperx84/claude-skills-mental-models
- **deciqAI/knowledge-skills**: premortem, sunk-cost-fallacy, circle-of-competence, expected-value-and-kelly, the-mom-test (lightly edited: coach-mode and promo footers removed). https://github.com/deciqAI/knowledge-skills
- **arbazex/decision-mental-models** (MIT, via ClaudSkills registry): 'What it asks / Applied / Non-obvious insight' format; Occam's razor, map≠territory, Hanlon's razor, Chesterton's fence, regret minimization, availability heuristic, systems thinking. https://github.com/ndesv21/openclaw-master-skills/tree/main/skills/decision-mental-models (original repo arbazex/decision-mental-models no longer available)
- Original 20 models: @kabirrtaj reel, 2026-10-25.
